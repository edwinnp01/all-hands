Spotlight · Security

63,000 brute-force hits, zero got through

After hardening, public brute-force events dropped from ~63,000+ to zero. We locked down public access ports and let Fail2Ban auto-ban repeat offenders — with Wazuh watching everything.

0+
brute-force events
→
0
public events now
  • ✓
    Restricted public / common access ports — closed the easy front doors.
  • ✓
    Fail2Ban auto-bans IPs after repeated failed attempts — no manual work.
  • ✓
    0 critical · 0 high severity alerts in the last 24 hours, confirmed in Wazuh.
